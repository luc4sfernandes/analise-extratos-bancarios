# Análise de Extratos Bancários

Software que automatiza processos de extratos bancários.

## Sobre

Este projeto reúne ferramentas para facilitar a leitura, a organização e a
análise de extratos bancários, reduzindo o trabalho manual em tarefas que hoje
são feitas arquivo por arquivo.

## Status

Em desenvolvimento. O projeto ainda está em fase inicial e a estrutura pode
mudar.
